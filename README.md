# Arizona Family Adventures — Sept 23–Oct 3, 2026

Two pages:

- `index.html` — Things To Do (26 activities, By Age, Tips)
- `dining.html` — Where To Eat (30 restaurants)

## How to add a place

1. Open `data/activities.js` (things to do) or `data/restaurants.js` (restaurants) on GitHub and click the pencil ✏️ to edit.
2. Copy one of the existing `{ ... }` blocks, paste it at the end of the list (just above the closing `];`), and change the text.
3. Make sure there is a comma between blocks.
4. Click **Commit changes**. The site updates in about a minute.

## How to change wording, colors, or tabs

Edit `index.html` or `dining.html` directly. Colors live at the top of each file in the `:root { ... }` block.
